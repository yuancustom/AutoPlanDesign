# 最终 Agent 的集成边界

这里是三能力编排项目，不是第四套建筑算法。当前只提供状态机设计，没有生产调度服务。

先读 CONTROL.md 第7~10节。能力调用通过合同，不直接import P1/P2/P3内部实现。首次集成使用文件适配器，之后可换本机HTTP/队列。每步保留revision/hash、job id、幂等键、checkpoint和实际工具结果。

模型路由基于benchmarks证据和本地资源；规划、图像生成、视觉复核可用不同模型，但同一16GB机器串行加载。提示词不能写审批、移动核心或改变输出格式。人工关卡绑定具体版本，编辑后使旧重建过期。

错误/取消/超时恢复先核验输入hash和有效审批，不能只根据文件存在跳过。禁止把三个包的capabilities输出当任务成功。M4才验收真实端到端Agent，之前仅验证合同和状态转移。
