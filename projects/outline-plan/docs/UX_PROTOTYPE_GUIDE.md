# P1 原型交互说明与体验路线

版本0.3.0；2026-09-11。代码在 `../prototype/index.html`。本文件补充既有P1详细设计，不替代它，不将原型能力当生产实现。

## 1. 先体验，再开发完整系统

打开HTML即可体验。没有外部JS、CDN、字体下载或API请求；可使用本机静态服务器。GitHub的blob页面展示源码，不会自动运行网页；没有在本轮配置Pages或公开部署服务。

建议5分钟路线：选择L形→把总宽改为36米→观察等比推导深度和面积→确认示例尺度→保存尺寸SVG/PNG→下一步将机柜改为25→看到数量差1→按规则重分配→核对9/8/8→选择两种图面配置→冻结输入→逐条查看示例流程→查看固定合成三层示意→收藏体验候选并导出记录。

这是易用性检查脚本，不是实际建筑案例；36米是临时体验数值，不能写回原项目为已确认尺寸。

## 2. 五个工作区

### 01 轮廓与尺寸
左侧项目导航，中间画布，右侧属性，底部固定主按钮。画布顶部操作栏有选择/拖顶点、闭合折线、平移、撤销/重做、缩放/适合。尺寸刻度随世界尺度变化，画布缩放不改几何。

不要求普通用户理解SVG文本；常用路径是绘制/上传后填一个已知尺寸，复杂参数折叠。高级API入口在原型只说明未实现的POST接口，不伪造接收成功。

本原型的坐标为SVG局部u/v，v向下，真实尺度通过总宽等比标定；导出的尺寸来自局部边长×比例。正式版按既有设计输出可逆pixel_to_world和米制XY/Z-up合同。原型导出JSON不是生产PlanRevision。

拖动点会使尺度确认失效，几何自交会恢复之前状态。折线工具依次点画布，点回首点闭合，Escape取消。支持非正交线作为交互演示，但正式首版求解器仍限正交矩形/L形，不扩大后端能力声明。

受限导入只支持一个polygon/rect或M/L/H/V/Z封闭路径；拒绝曲线、变换、多路径、脚本及资源引用，提示具体原因。它不能替代完整SVG导入器。工程尺寸SVG含文字，原型不承诺可直接重新导入；生产版要分开canonical.svg和engineering.svg。

### 02 功能参数
“整栋总量卡片＋楼层表＋每房分配”同屏。工位、机柜、机房、层数是常用输入；先看到总量差额再保存。修改总量不会悄悄自动改分层数据，用户点“重新分配”后才写入规则建议。

默认3层、24工位、24柜、3机柜机房，办公席位与会议席位/控制台席位分开（后两者在完整表单中实现，本原型不计入总工位）。25柜的均分为9+8+8，不能丢余数。输入负数、小数、空值与0要区分。原型机房专指放置机柜的房间，机械设备房后续用不同模板。

高级墙厚/检修净距在原型仅说明，未执行空间容量检查。绿色提示写“数量一致”，不能写“布局可行”。

### 03 模型实验
三模式：规划能力、图面表现、完整链路。模型名称是配置意向，全部未连接。每个卡片保留NOT_RUN/待适配；没有性能分数或假进度。

选规划模式时整栋规划调用不乘楼层数；图面模式配置×种子×楼层；完整链路还应独立统计规划调用，本原型只展示图面预算，正式运行器要拆两层。每个图面实验必须固定真实layout hash，原型快照只说明意向，不声称具备可入队参数。

### 04 设计过程
前两条为真实浏览器操作（快照与数量检查）；后续点击展开的是公开流程示例，逐项标“未执行”。不播放伪思考过程，不生成假采样百分比。正式版事件来源为持久worker/solver/provider，显示依据、冲突、工具结果及原图引用。

输入发生变化后快照失效。浏览器中计算真实SHA-256用于体验对照，但不是服务器授权、不可抵赖审计或正式审批证据。

### 05 结果对比
三幅固定合成示意辅助查看页布局。显著提示：它们不响应当前参数、未经过排房、不是模型生成图。模型表的生成、检查、耗时/内存均空缺或NOT_RUN。收藏只记录体验偏好；“确认并交给P2”不可用。

正式版按整栋candidate接受，混合不同候选楼层需新版本及跨层复核；支持原图/最终图/边界叠加同步缩放与差异查看。

## 3. 降低使用负担的约定

每页只保留一个主要下一步操作；下一步被阻止时显示具体修正动作，不只有红色失败。快捷默认可改，数据来源可见；复杂信息按需展开。保留上一步的输入，不让用户反复重填。优先自动算总量/余数/尺寸，不自动替用户批准几何变更。

所有按钮用文字说明，键盘焦点明显；重要状态不仅靠颜色。桌面优先，窄屏堆叠布局；真实绘图仍建议大屏。试用重点不是“看得漂亮”，而是能找到入口、知道被阻止的原因、看懂要求与实际差异。

## 4. 体验反馈与代码任务

请按五项记录用户体验：是否能无需指导完成导入；是否理解尺寸不是SVG像素；能否发现25柜分配差额；能否分清未连接模型与真实结果；能否知道收藏不等于批准。

体验检查未实施人工样本测试，不承诺5分钟全部用户可完成。可记录每步耗时、卡点、撤销次数和误操作；不采集未经允许的图纸或个人数据。

正式实现映射：SVG-01/ UI-01/ DIM-01 负责导入绘图导出，FORM-01负责完整表单，ALG-01负责真实布局，MODEL-01/TRACE-01负责模型和公开事件，EXP-01/ACCEPT-01负责同源对比和交接。原型代码为参考，不覆盖这些任务的完成状态。
