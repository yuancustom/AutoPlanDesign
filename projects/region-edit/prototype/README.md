# P2 区域重绘交互原型

**可操作的五页面原型，不是模型重绘服务。** 用户已明确要求将此原型同步到公共 GitHub，包括内置平面图的预览副本；任何浏览器编辑历史和导出的个人工程都不上传。

## 打开与体验

下载/克隆仓库后，保留此目录全部文件，用浏览器打开 `index.html`。无需 npm、构建依赖或模型。GitHub 的 blob 页面只展示源码，不执行网页；本次未启用 GitHub Pages。

需要单文件 HTML 时，在此目录执行（Python 标准库，无需额外依赖）：

```bash
python build_standalone.py --out P2_区域重绘交互原型.html
```

已有输出不会覆盖；换个新文件名。也可运行仓库 Actions 中的 **P2 interaction prototype (no model)**，在成功运行的 Artifacts 中取得生成的单文件 HTML 和验证结果。

推荐操作：右栏「机柜排布」→「预览修改范围」→勾选确认→「生成演示候选」→滑杆比较→「接受，保存为 r1」→「版本历史」选 r0→「恢复此版本」。恢复产生 r2，原 r0/r1 保留。

## 交互内容

| 页面 | 可操作内容 |
|---|---|
| 编辑工作台 | 涂抹、橡皮、保护笔、矩形、缩放平移、笔画撤销重做、描述 |
| 候选对比 | 滑杆/并排/差异、原始演示候选与合成候选、接受/拒绝、再试一次 |
| 版本历史 | 历史查看、与当前比较、恢复旧内容、撤回上一次版本修改 |
| 过程记录 | 来源、笔画/蒙版、原话、参数、像素检查、接受/拒绝/恢复事件 |
| 操作与实现 | 前端原型与正式本机 API、数据库、模型、几何同步的职责映射 |

草稿撤销仅改变笔画；拒绝候选不改变当前版本；恢复正式版本追加新版本，不删除历史。当前 IndexedDB 是浏览器暂存，不是生产级事务审计；重要结果使用「保存工程」导出备份。

## 与上一轮附件的区别

交互脚本、DOM 和样式来自上一轮交付，改为顺序加载的本地文件，并保留单文件合成工具。内置图片保持 768×512，以 WebP quality=90 压缩供预览，**不是原始 PNG 的逐像素或逐字节副本**。这不改变笔画坐标和保护规则，但不应用于原始图纸精度评价。原始 HTML 附件不被改写；哈希和转换信息见 `PROVENANCE.json`。

`使用说明与实现映射.md`、`交互测试报告.json` 和 `交互测试摘要.md` 保留原交付说明及27项历史测试，文档开头注明了同步差异。截图仍在原附件包，不在本目录。

本次仓库版新增回归覆盖8组交互场景，见 `publication-test.json`。它使用允许的内联浏览器页面执行合成HTML；当前环境禁止 file/localhost 导航，所以不声称本机文件导航或 IndexedDB 跨会话测试已经通过。CI 使用标准 Chromium 可另测目录及单文件打开方式。

## 验证

```bash
python -m pip install playwright
python -m playwright install chromium
python build_standalone.py --out /tmp/p2-standalone.html
python smoke_test.py --standalone /tmp/p2-standalone.html --out /tmp/p2-test.json
```

使用现有浏览器可传 `--browser /path/to/chromium`。仅在受限测试环境使用 `--inline` 测试合成文件，报告会明确标记，不禁用浏览器安全策略。

**没有 AI 推理、自动识墙、真实尺度、建筑几何同步或 P3 交付。** 候选按右栏演示类型由程序绘制，自由提示词只记录；所有版本保持 IMAGE_ONLY。不要把本原型或测试通过当成 P2-03/P2-04 生产任务完成。
